# WSudoku website

Public website files for WSudoku by Kvass Games.

This repository contains only the static website, approved screenshots, and
branding needed for GitHub Pages. The game source code is kept in a separate
private repository and is not published here.

The site is deployed to:

<https://perezhoginviktor.github.io/WSudoku-site/>

The public WSudoku account-deletion resource is deployed to:

<https://perezhoginviktor.github.io/WSudoku-site/delete-account/>

The WSudoku privacy policy is deployed to:

<https://perezhoginviktor.github.io/WSudoku-site/privacy/>

The paid Windows and Linux builds are distributed through Steam. The Steam
store listing is awaiting public release. Android currently has a separate,
debug-signed test APK and is not presented as a desktop download.

The Steam button icon is a one-glyph subset of JetBrains Mono Nerd Font.
Its SIL Open Font License is included at `assets/fonts/OFL.txt`.

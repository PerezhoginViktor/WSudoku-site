# WSudoku website

Public website files for WSudoku by Kvass Games.

This repository contains only the static website, approved screenshots, and
branding needed for GitHub Pages. The game source code is kept in a separate
private repository and is not published here.

The site is deployed to:

<https://perezhoginviktor.github.io/WSudoku-site/>

WSudoku is in active development. Store releases, production online services,
and final privacy/account-deletion pages are not live yet.
